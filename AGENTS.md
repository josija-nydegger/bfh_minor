# KI-USAGE
Jede Ergänzung durch KI wird in `KI-USAGE.md` festgehalten
Tabellenspalten: Datum | Werkzeug | Wofür eingesetzt? | Was übernommen/verändert? | Wie geprüft?
Kurz fassen: ein bis zwei Sätze pro Zelle.
Gibt es am selben Tag bereits einen Eintrag zum selben Thema, wird dieser ergänzt statt eine neue Zeile anzulegen.
Neue Zeile nur bei neuem Thema oder neuem Tag.
Werkzeug konkret angeben (z. B. Claude Code (Sonnet 5)).
„Wie geprüft?": angeben, was Agent selbst geprüft hat (Test, Regressionsvergleich, Build); was der Student noch prüfen muss, als „ausstehend: …" vermerken.
